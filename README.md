#FileFlow Report Exporter
PHP application that exports reports in a txt, json, and csv format. It utilizes design patterns such as Singleton to manage app settings and Factory Method for creating the appropriate file exporters.

##Requirements
**PHP CLI and Composer**

##Setup Commands
```
composer install
composer dump-autoload
```
##Run Commands
```
php app.php txt
php app.php json
php app.php csv
```
